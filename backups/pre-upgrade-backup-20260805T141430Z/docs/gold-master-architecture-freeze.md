# Gold Master Architecture Freeze

## Scope
This release freezes the current enterprise-grade architecture around the shared intelligence layer, the workflow engine, the automation orchestrator, the recovery engine, and the hardened server runtime.

## Preserved Principles
- Preserve the existing user experience and route structure.
- Maintain one normalized source of truth for underwriting and decision outputs.
- Preserve persisted deal values across save, refresh, and reopen flows.
- Prefer recovery-safe and audit-friendly workflow execution.
